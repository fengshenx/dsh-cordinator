# 项目初始化

把仓库工程约定固化到目标项目，使后续所有会话自动遵守，而不依赖人工重复交代。

## 做什么

1. 确认目标项目目录（绝对路径），目录必须已存在。
2. 读本 skill 的 `references/conventions.md`，得到约定正文。
3. 读目标项目的 `AGENTS.md`（不存在就视为空）。
4. 把约定正文并入受管区块，保留文件里的其它内容：
   - 区块以 `<!-- dsh-coordinator:conventions:start -->` 开头、`<!-- dsh-coordinator:conventions:end -->` 结尾。
   - 已有同区块就整体替换该区块；没有就追加到文件末尾；空文件直接写入区块。
5. 用宿主的文件编辑能力写回 `AGENTS.md`，向用户报告写入位置与要点。

dsh 读取 `AGENTS.md` 作为系统提示段落，因此写入后立即对模型生效。

## 边界

- 幂等：重复执行只替换受管区块。
- **不覆盖**项目自己的 `AGENTS.md` 内容。若项目已有约定，说明两者并存，不要删掉其一。
- 约定文本以 `references/conventions.md` 为准；需要调整约定时改该文件再重新写入。
- 初始化只做一次。项目已有约定的，先读一遍再决定是否还需要写入。
- 约定不是项目特有规则的替代品：架构不变式、目录拓扑、发布流程仍由项目自己的文档定义。

## 资源
