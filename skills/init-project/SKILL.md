# 项目初始化

把仓库工程约定固化到目标项目，使后续所有会话自动遵守，而不依赖人工重复交代。

## 做什么

1. 确认目标项目目录（绝对路径），目录必须已存在。
2. 调用 `init_project` 工具，参数 `path` 指向该目录。
3. 约定写入项目的 `AGENTS.md` 受管区块；dsh 读取 `AGENTS.md` 作为系统提示段落，因此写入后立即对模型生效。
4. 向用户报告写入位置与要点。

## 边界

- 工具只替换自己管理的受管区块，不动项目已有的其它约定；重复调用是幂等的。
- 工具**不覆盖**项目自己的 `AGENTS.md` 内容。若项目已有约定，说明两者并存，不要删掉其一。
- 约定文本本身在 `references/conventions.md`，是本 skill 的资源；需要调整约定时改该文件再重新写入，不要在工具调用参数里传正文。
- 初始化只做一次。项目已有约定的，先读一遍再决定是否还需要写入。
- 约定不是项目特有规则的替代品：架构不变式、目录拓扑、发布流程仍由项目自己的文档定义。

## 资源

- `references/conventions.md` —— 写入的约定正文。
